# Abandoned but not Forgotten

An interactive space museum about the hardware NASA left behind on the Moon, on Mars and in deep space.
Built for the hackathon challenge: *Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars.*

Open `index.html` in any modern browser. It is a single file with no build step.

## Features
- Cinematic landing page with a looping galaxy video
- 12-scene story mode, narrated scene by scene, where the machines speak in the first person
- Ghost Hardware Map: tap dots on the Moon and Mars to hear each machine's story
- Scroll-driven timeline from 1967 to 2021
- Archive of 13 missions with photos, key details, 8 technical specs and a quiz, at 3 reading levels (ages 0-5, 6-10, 11-16)
- Moon / Mars / Deep space filters
- Keyboard accessible, reduced-motion support, mobile friendly

## Run locally
Double-click `index.html`, or serve the folder: `python -m http.server 8000` then visit http://localhost:8000
